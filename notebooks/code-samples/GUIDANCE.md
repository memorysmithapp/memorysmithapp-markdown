# Code Samples

> [!info]
> One fenced block per language a note can be highlighted in, so each one can
> be seen drawn, and chosen from a code block's language in edit mode.

## Writing rules

1. **One language per note**, named after it, with the fence's info string it
   is written with and any alias that names it too.
2. **The code is real**: something a notebook would keep, short enough to read
   on a phone, and correct in its language.
3. A note says, in its own prose, which info string it is written with, so the
   page explains the fence beside the fence.

## Required frontmatter

`name`, `aliases`, `tags`, `type` (`sample`), `fence` (the info string),
`created`, `updated`.
